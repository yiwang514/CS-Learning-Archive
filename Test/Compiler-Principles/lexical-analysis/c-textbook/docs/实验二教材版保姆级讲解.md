## 1. 先看懂程序在做什么

词法分析器可以理解为一个“拆单词机器”。

例如源程序：

```text
const m = 7;
```

程序最终会把它拆成：

```text
const    KEYWORD      CONSTSYM
m        IDENTIFIER   m
=        SPECIAL      EQL
7        INTEGER      7
;        SPECIAL      SEMICOLON
```

这里每一行就是一个 Token。一个 Token 主要包含三部分：

- `Word`：源程序里原来写的是什么，例如 `const`
- `Category`：它属于哪一类，例如关键字、标识符、整数、特殊符号
- `Value`：教材中的符号名称或实际值，例如 `CONSTSYM`、`m`、`EQL`、`7`

本程序只负责拆单词，不负责判断语法是否正确。

例如程序只负责判断 `read` 是关键字，不负责检查 `read` 后面有没有左括号。那是语法分析阶段的任务。

## 2. 教材版和原独立版的区别

项目里现在有两套词法分析器。

原独立版：

```text
lexical-analysis/c/src/pl0lex.c
```

教材风格版：

```text
lexical-analysis/c-textbook/src/pl0_lexer.c
```

如果老师要求复刻王生原、董渊 C 语言版，应使用第二套。

教材版保留了这些教材特征：

- 一个头文件和一个源文件
- `enum symbol` 符号枚举
- `word`、`wsym`、`ssym` 三张表
- 独立函数 `init()`、`getch()`、`getsym()`、`error()`
- 13 个保留字，包含 `read` 和 `write`
- 不等号使用教材中的 `#`
- 源码行以代码地址和源文本的形式回显
- 错误以 `****...!n` 形式输出

注意：教材 C 版关键字采用小写。本实现也保持这个规则。`BEGIN` 不会被当成关键字，而会被当成非法字符处理。

### 说明整体流程

“程序主要分成四步。第一步调用 `init()` 初始化保留字表和单字符符号表。第二步通过 `getch()` 从源文件中一个字符一个字符地读取。第三步由独立过程 `getsym()` 完成词法分析。最后把识别出的 Token 保存下来，统一打印成 Word、Category、Value 表。”

### 说明 `getch()`

“`getch()` 是教材里的字符读取函数。它每次发现当前行已经读完，就从文件里读下一行，同时把源程序回显到屏幕。`cc` 表示当前读到这一行第几个字符，`ll` 表示这一行有多长。当 `cc` 等于 `ll` 时，说明这一行已经处理完，需要读下一行。”

“`getsym()` 是核心函数。一开始它会跳过空格、回车、换行和制表符。如果读到 `/*`，就进入注释处理，忽略注释里的内容。如果当前字符是小写字母，就继续读取字母和数字，组成一个完整单词，再通过折半查找判断它是保留字还是普通标识符。”

“如果当前字符是数字，就连续读取数字，保存整数内容。如果当前字符是冒号，就继续看下一个字符是不是等号，如果是就组成 `:=`，否则报错。如果当前字符是小于号或大于号，也会继续看一个字符，判断是不是 `<=` 或 `>=`。其他符号通过 `ssym` 表查询。”

### 说明 Token 表

“识别成功后，`record_current_token()` 会把 Token 保存起来。最后 `print_tokens()` 统一打印。比如 `read` 的类别是 KEYWORD，教材符号名是 READSYM；标识符 `a` 的类别是 IDENTIFIER；整数 7 的类别是 INTEGER。”

## 6. 头文件 `pl0_t.h` 逐个解释

头文件的作用是把常量和全局变量的名字先告诉 C 语言，避免多个文件之间产生冲突。

### 6.1 三个基本限制

```c
#define norw 13
#define nmax 14
#define al 10
```

含义：

- `norw = 13`：保留字数量是 13 个
- `nmax = 14`：整数最多 14 位
- `al = 10`：标识符最大长度是 10

`symnum = 32` 表示 `enum symbol` 中一共有 32 个符号种别。

### 6.2 `enum symbol`

```c
enum symbol {
    nul,       ident,     number,    plus,      minus,
    times,     slash,     oddsym,    eql,       neq,
    lss,       leq,       gtr,       geq,       lparen,
    rparen,    comma,     semicolon, period,    becomes,
    beginsym,  endsym,    ifsym,     thensym,   whilesym,
    writesym,  readsym,   dosym,     callsym,   constsym,
    varsym,    procsym
};
```

这是符号“编号表”。

C 语言会给枚举成员自动编号：

```text
nul = 0
ident = 1
number = 2
plus = 3
...
procsym = 31
```

程序不需要记住每个数字，只会通过名字使用，例如 `sym = number`。

注意枚举里 `oddsym` 排在普通运算符中间，不在关键字集中间。因此判断关键字时要单独处理 `odd`。

### 6.3 全局变量和表格

```c
extern FILE *fin;
extern char ch;
extern enum symbol sym; 
extern char id[al + 1];
extern int num;
extern int cc;
extern int ll;
extern int cx;
extern char line[81];
extern char a[al + 1];
extern char word[norw][al];
extern enum symbol wsym[norw];
extern enum symbol ssym[256];
extern int err;
```

它们的用途：

| 变量 | 作用 |
| --- | --- |
| `fin` | 打开的 PL/0 源文件 |
| `ch` | 当前刚读到的字符 |
| `sym` | 当前 Token 的符号类别 |
| `id` | 当前标识符或关键字文本 |
| `num` | 当前整数的数值 |
| `cc` | 当前行已经读到第几个字符 |
| `ll` | 当前行的长度 |
| `cx` | 教材源码回显每行前面的代码地址 |
| `line` | 当前源程序行的字符缓冲区 |
| `a` | 临时存放标识符或关键字 |
| `word` | 13 个保留字的文本表 |
| `wsym` | 保留字文本对应的符号编号 |
| `ssym` | 单字符对应的符号编号 |
| `err` | 错误数量 |

## 7. 源文件 `pl0_lexer.c` 的函数地图

源文件内部还有几个只在本文件使用的变量：

```c
static struct token_record tokens[max_tokens];
static int token_count;
static int input_finished;
static char number_text[64];
```

它们的作用：

- `tokens`：保存扫描出来的全部 Token
- `token_count`：当前已经保存了多少个 Token
- `input_finished`：源文件是否已经读到末尾
- `number_text`：原样保存数字文本，防止过大的整数在打印时溢出

其中 `max_tokens` 表示最多保存多少个 Token，`token_text_size` 表示每个 Token 字段最多保存多少个字符：

```c
#define max_tokens 2048
#define token_text_size 128
```

Token 记录的结构是：

```c
struct token_record {
    char word[token_text_size];
    char category[token_text_size];
    char value[token_text_size];
};
```

对应输出表的三列：

```text
Word / Category / Value
```

先看总表：

| 函数 | 等级 | 一句话作用 |
| --- | --- | --- |
| `is_keyword_symbol` | C | 判断当前符号是不是关键字符号 |
| `copy_text` | C | 安全复制字符串 |
| `add_token` | B | 往 Token 表中增加一行 |
| `record_error_token` | C | 往 Token 表中增加错误行 |
| `record_current_token` | A | 把当前符号转换成 Token 表的一行 |
| `error` | A | 输出教材式错误标记 |
| `getch` | A | 一次读取一个源字符，并回显源代码 |
| `init` | A | 建立保留字表和特殊符号表 |
| `getsym` | A | 核心词法分析过程 |
| `print_tokens` | B | 打印最后的 Token 表 |
| `main` | B | 打开文件、循环调用 `getsym()`、输出结果 |

录制时重点讲 A 级函数。B 级知道作用就行。C 级被问到时按表格里的话回答即可。

## 8. A 级函数 1：`getch()`

完整代码：

```c
int getch(void)
{
    if (cc == ll) {
        if (input_finished) {
            printf("program incomplete\n");
            return -1;
        }

        ll = 0;
        cc = 0;
        printf("%d ", cx);

        while (1) {
            int c = fgetc(fin);
            if (c == EOF) {
                input_finished = 1;
                break;
            }
            ch = (char)c;
            printf("%c", ch);
            if (ll < 80) {
                line[ll++] = ch;
            }
            if (ch == '\n') {
                break;
            }
        }

        if (ll == 0 && input_finished) {
            printf("\nprogram incomplete\n");
            return -1;
        }

        if (ll < 80) {
            line[ll++] = ' ';
        }
        printf("\n");
    }

    ch = line[cc];
    cc++;
    return 0;
}
```

逐段解释：

1. `cc == ll` 表示当前行已经全部处理完。
2. 如果文件也已经结束，输出 `program incomplete`，返回 `-1`。
3. 否则把 `ll` 和 `cc` 清零，准备读取下一行。
4. `printf("%d ", cx)` 输出教材格式的行首编号。
5. `fgetc(fin)` 每次只读一个字符。
6. 每读到一个字符，立即用 `printf("%c", ch)` 回显。
7. 字符同时放进 `line` 数组。
8. 遇到换行符 `\n` 就结束这一行。
9. 行末补一个空格，作为扫描保护字符。
10. `ch = line[cc]` 把当前字符交给 `getsym()`。
11. `cc++` 表示下一次取当前行的下一个字符。

理解 `cc` 和 `ll` 的最简单方法：

```text
line:    c o n s t   m
下标:    0 1 2 3 4 5 6
cc:      当前读到第几个
ll:      这一行总共有多少个
```

当 `cc` 追到 `ll` 时，说明这一行读完了。

## 9. A 级函数 2：`init()`

`init()` 要做三件事。

### 9.1 清空单字符表

```c
for (i = 0; i < 256; i++) {
    ssym[i] = nul;
}
```

先把 256 个字符都设成 `nul`，表示“默认不认识”。

### 9.2 登记单字符符号

```c
ssym['+'] = plus;
ssym['-'] = minus;
ssym['*'] = times;
ssym['/'] = slash;
ssym['('] = lparen;
ssym[')'] = rparen;
ssym['='] = eql;
ssym[','] = comma;
ssym['.'] = period;
ssym['#'] = neq;
ssym[';'] = semicolon;
```

例如以后读到 `#` 时，程序查 `ssym['#']`，会得到 `neq`。

### 9.3 登记保留字

教材要求保留字按字母顺序排列，因为后面用折半查找：

```text
begin
call
const
do
end
if
odd
procedure
read
then
var
while
write
```

代码对应：

```c
strcpy(word[0], "begin");
strcpy(word[1], "call");
strcpy(word[2], "const");
strcpy(word[3], "do");
strcpy(word[4], "end");
strcpy(word[5], "if");
strcpy(word[6], "odd");
strcpy(word[7], "procedure");
strcpy(word[8], "read");
strcpy(word[9], "then");
strcpy(word[10], "var");
strcpy(word[11], "while");
strcpy(word[12], "write");
```

然后建立文本和符号编号的对应关系：

```c
wsym[0] = beginsym;
wsym[1] = callsym;
wsym[2] = constsym;
...
wsym[12] = writesym;
```

例如：

```text
word[8] = "read"
wsym[8] = readsym
```

以后查到下标 8，就知道这是 `read`，对应符号是 `readsym`。

## 10. A 级函数 3：`getsym()`

这是整个程序最重要的函数。下面分成五段讲。

为便于阅读，下面的代码片段省略了部分 `getch()` 返回 `-1` 时的错误检查。完整代码以 `lexical-analysis/c-textbook/src/pl0_lexer.c` 为准。

### 10.1 第一段：跳过空白

```c
while (ch == ' ' || ch == '\n' || ch == '\r' || ch == '\t') {
    if (getch() == -1) {
        return -1;
    }
}
```

空格、换行、回车、制表符没有语法意义，所以一直读下一个字符，直到遇到真正的 Token 开头。

### 10.2 第二段：跳过注释

```c
if (ch == '/') {
    if (getch() == -1) {
        return -1;
    }
    if (ch == '*') {
        if (getch() == -1) {
            return -1;
        }
        while (1) {
            if (ch == '*') {
                if (getch() == -1) {
                    error(38);
                    return -1;
                }
                if (ch == '/') {
                    if (getch() == -1) {
                        return -1;
                    }
                    break;
                }
            } else if (getch() == -1) {
                error(38);
                return -1;
            }
        }
        continue;
    }

    sym = slash;
    record_current_token();
    return 0;
}
```

运行过程：

1. 当前字符是 `/`。
2. 读下一个字符。
3. 如果下一个是 `*`，说明进入 `/* ... */` 注释。
4. 一直读到 `*/`。
5. 注释结束后 `continue`，重新开始识别下一个 Token。
6. 如果 `/` 后面不是 `*`，它就是除法符号，记录成 `slash`。

如果找不到 `*/`，输出错误码 38。

### 10.3 第三段：识别标识符或保留字

```c
if (ch >= 'a' && ch <= 'z') {
    k = 0;
    identifier_too_long = 0;
    do {
        if (k < al) {
            a[k] = ch;
            k++;
        } else {
            identifier_too_long = 1;
        }
        if (getch() == -1) {
            return -1;
        }
    } while ((ch >= 'a' && ch <= 'z') || (ch >= '0' && ch <= '9'));

    a[k] = '\0';
    strcpy(id, a);
```

这段负责读完整单词：

- 第一个字符必须是小写字母
- 后面可以继续读小写字母和数字
- 最多保存 10 个字符
- 超过 10 个字符时，把 `identifier_too_long` 设置为 1
- 最后给字符串补上结束符 `\0`

然后使用折半查找：

```c
i = 0;
j = norw - 1;
do {
    k = (i + j) / 2;
    if (strcmp(id, word[k]) <= 0) {
        j = k - 1;
    }
    if (strcmp(id, word[k]) >= 0) {
        i = k + 1;
    }
} while (i <= j);

if (i - 1 > j) {
    sym = wsym[k];
} else {
    sym = ident;
}
```

简单理解：

- 从 13 个保留字中间开始比较
- 如果当前单词比中间的小，就往左半边找
- 如果当前单词比中间的大，就往右半边找
- 找到就是关键字
- 找不到就是普通标识符

例如：

```text
read   在 word 表中找到 -> sym = readsym
total  不在 word 表中 -> sym = ident
```

### 10.4 第四段：识别整数

```c
} else if (ch >= '0' && ch <= '9') {
    k = 0;
    i = 0;
    num = 0;
    sym = number;
    do {
        if (i < (int)sizeof(number_text) - 1) {
            number_text[i] = ch;
            i++;
        }
        num = 10 * num + ch - '0';
        k++;
        if (getch() == -1) {
            return -1;
        }
    } while (ch >= '0' && ch <= '9');
    number_text[i] = '\0';

    k--;
    if (k > nmax) {
        error(30);
    }
    if (ch >= 'a' && ch <= 'z') {
        error(39);
        record_error_token("", "number cannot be followed by a letter");
    }
```

这段把连续的 `0` 到 `9` 读成整数，同时把原始数字保存到 `number_text`，方便最后打印 Token 表。

```text
数字 85：

第一次：num = 0 * 10 + 8 = 8
第二次：num = 8 * 10 + 5 = 85
```

`nmax` 是 14，所以超过 14 位就报错。

```c
if (ch >= 'a' && ch <= 'z') {
    error(39);
    record_error_token("", "number cannot be followed by a letter");
}
```

如果写成 `12abc`，数字后面直接紧跟字母，就输出错误码 39。

### 10.5 第五段：识别冒号、小于号和大于号

冒号：

```c
} else if (ch == ':') {
    getch();
    if (ch == '=') {
        sym = becomes;
        getch();
    } else {
        sym = nul;
        error(19);
        record_error_token(":", "':' must be followed by '='");
        return 0;
    }
}
```

`:` 只有和 `=` 连在一起才合法，也就是赋值符号 `:=`。

小于号：

```c
} else if (ch == '<') {
    getch();
    if (ch == '=') {
        sym = leq;
        getch();
    } else {
        sym = lss;
    }
}
```

- `<=` 是 `leq`
- `<` 是 `lss`

大于号：

```c
} else if (ch == '>') {
    getch();
    if (ch == '=') {
        sym = geq;
        getch();
    } else {
        sym = gtr;
    }
}
```

- `>=` 是 `geq`
- `>` 是 `gtr`

### 10.6 最后：查单字符表

```c
sym = ssym[(unsigned char)ch];
if (sym == nul) {
    error(37);
    record_error_token(invalid, "illegal character");
} else if (sym != period) {
    getch();
}
```

`ssym` 是 `init()` 初始化的单字符表。

例如：

```text
+ -> plus
- -> minus
* -> times
/ -> slash
( -> lparen
) -> rparen
= -> eql
# -> neq
```

如果查出来是 `nul`，说明这个字符既不是合法单词，也不是合法特殊符号，于是报错并记录 ERROR Token。

## 11. A 级函数 4：`record_current_token()`

完整代码：

```c
static void record_current_token(void)
{
    if (sym == ident) {
        add_token(id, "IDENTIFIER", id);
    } else if (sym == number) {
        add_token(number_text, "INTEGER", number_text);
    } else if (is_keyword_symbol()) {
        add_token(id, "KEYWORD", symbol_name[sym]);
    } else if (sym >= plus && sym <= becomes && sym != oddsym) {
        add_token(symbol_text[sym], "SPECIAL", symbol_name[sym]);
    } else if (sym == nul) {
        record_error_token("NUL", "unrecognized symbol");
    }
}
```

它把 `getsym()` 识别出的结果放进 Token 表：

- `sym == ident`：记录为 `IDENTIFIER`
- `sym == number`：记录为 `INTEGER`
- 关键字：记录为 `KEYWORD`
- 特殊符号：记录为 `SPECIAL`
- `nul`：记录为 `ERROR`

例如：

```text
sym = readsym
id  = "read"
```

最终会生成：

```text
read        KEYWORD        READSYM
```

`sym >= plus && sym <= becomes && sym != oddsym` 这种写法看起来奇怪，是因为 `oddsym` 在枚举中夹在运算符编号中间。如果不排除 `oddsym`，`odd` 会被错误地当成特殊符号。

## 12. B 级函数：知道作用即可

### 12.1 `main()`

`main()` 是程序入口，负责：

1. 输出 `Input pl/0 file?`
2. 如果有命令行参数，就直接把参数当文件名
3. 如果没有参数，就等待用户输入文件名
4. 打开文件
5. 调用 `init()`
6. 反复调用 `getsym()`
7. 遇到句号 `period` 停止
8. 调用 `print_tokens()`
9. 关闭文件
10. 有错误返回 1，没有错误返回 0

### 12.2 `print_tokens()`

完整代码：

```c
void print_tokens(void)
{
    int i;

    printf("\nWord                Category            Value\n");
    for (i = 0; i < token_count; i++) {
        printf("%-20s%-20s%-20s\n",
               tokens[i].word, tokens[i].category, tokens[i].value);
    }
}
```

它打印表头，然后从第 0 行开始逐行输出已经保存的 Token。

`%-20s` 的意思是：按字符串输出，占 20 个字符宽，左对齐。

### 12.3 `add_token()`

它把 `word`、`category`、`value` 三部分复制到 Token 数组中，然后让 `token_count` 加一。

可以理解为：

```text
tokens[token_count] = 新的一行
token_count++
```

### 12.4 `error()`

完整代码：

```c
void error(int n)
{
    char space[81];
    int i;

    for (i = 0; i < 80; i++) {
        space[i] = ' ';
    }
    space[80] = '\0';

    if (cc > 0 && cc <= 80) {
        space[cc - 1] = '\0';
    }

    printf("****%s!%d\n", space, n);
    err++;
}
```

它的作用是打印教材式错误位置：

```text
****                    !30
```

前面补空格是为了让错误尽量对齐到出错位置，最后打印感叹号和错误编号。

本程序使用的错误编号：

| 编号 | 含义 |
| --- | --- |
| `19` | 单独的 `:` 后面没有 `=` |
| `30` | 整数超过 14 位 |
| `36` | 标识符超过 10 个字符 |
| `37` | 非法字符 |
| `38` | 注释没有闭合 |
| `39` | 数字后紧跟字母 |

## 15. 常见问题与回答

### 问：为什么源码每行前面都是 0？

答：因为 `getch()` 输出的是教材代码地址 `cx`。完整编译器生成 P-code 后 `cx` 会变化，本实验只做词法分析，没有代码生成，所以一直是 0。

### 问：为什么 `read` 和 `write` 是关键字？

答：教材 C 版的 13 个保留字中包含 `read` 和 `write`，它们主要通过 `word` 和 `wsym` 两张表识别。

### 问：怎么区分关键字和标识符？

答：先把首字母到后面的字母数字全部读完，得到完整单词，再用折半查找在 `word` 表里查找。找到就是关键字，找不到就是标识符。

### 问：为什么用折半查找？

答：因为 `word` 表已经按字母顺序排好，折半查找不用从头一个个比较，效率更高，这也是教材案例的处理方式。

### 问：为什么 `#` 表示不等于？

答：这本教材的 C 版案例用单字符 `#` 表示 `neq`，不是用两个字符 `<>`。

### 问：注释在哪里处理？

答：在 `getsym()` 开头。发现 `/` 后再读一个字符，如果是 `*`，就一直跳到 `*/`。

### 问：为什么单独一个冒号要报错？

答：PL/0 的赋值符号是 `:=`，单独 `:` 不是合法符号。

### 问：Token 表为什么最后才打印？

答：`getsym()` 扫描时先把每个 Token 存进 `tokens` 数组，全部扫描结束后再由 `print_tokens()` 统一打印，避免和教材的源码回显混在一起。
