## 1. 阅读方法

不要一开始就试图一次看懂 470 多行。

建议按下面顺序看：

1. 先看头文件 `pl0_t.h`，知道程序用到了哪些名字。
2. 再看源文件最上面的宏、结构体和全局变量。
3. 看 `init()`，知道保留字表和符号表怎么建立。
4. 看 `getch()`，知道文件字符怎么读进来。
5. 重点看 `getsym()`，这是词法分析的核心。
6. 看 Token 如何保存和打印。
7. 最后看 `main()`，把整个执行流程串起来。

### 2.1 `#ifndef`、`#define` 和 `#endif`

```c
#ifndef PL0_TEXTBOOK_H
#define PL0_TEXTBOOK_H
...
#endif
```

这三行叫“头文件保护”。

作用是防止同一个头文件被重复包含。

可以理解成：

```text
如果没有定义过 PL0_TEXTBOOK_H
    就定义它，并继续读取这个头文件
否则
    直接跳过
```

如果没有这层保护，头文件有时会被包含两次，导致变量或类型重复定义。

### 2.2 `#include <stdio.h>`

```c
#include <stdio.h>
```

因为头文件里使用了 `FILE *`，而 `FILE` 类型定义在 `stdio.h` 中，所以必须包含它。

### 2.3 `norw`、`nmax`、`al`、`symnum`

```c
#define norw 13
#define nmax 14
#define al 10
#define symnum 32
```

这四个是编译前会替换的常量：

| 名字 | 值 | 含义 |
| --- | ---: | --- |
| `norw` | 13 | 保留字数量 |
| `nmax` | 14 | 整数最多 14 位 |
| `al` | 10 | 标识符最大长度 |
| `symnum` | 32 | 符号种别数量 |

### 2.4 `enum symbol`

```c
enum symbol {
    nul,       ident,     number,    plus,      minus,
    times,     slash,     oddsym,    eql,       neq,
    lss,       leq,       gtr,       geq,       lparen,
    rparen,    comma,     semicolon, period,    becomes,
    beginsym,  endsym,    ifsym,     thensym,   whilesym,
    writesym,  readsym,   dosym,     callsym,   constsym,
    varsym,    procsym
};
```

这是 C 语言的枚举类型。

枚举会自动给名字编号，从 0 开始：

```text
nul       = 0
ident     = 1
number    = 2
plus      = 3
minus     = 4
times     = 5
slash     = 6
oddsym    = 7
eql       = 8
neq       = 9
lss       = 10
leq       = 11
gtr       = 12
geq       = 13
lparen    = 14
rparen    = 15
comma     = 16
semicolon = 17
period    = 18
becomes   = 19
beginsym  = 20
endsym    = 21
ifsym     = 22
thensym   = 23
whilesym  = 24
writesym  = 25
readsym   = 26
dosym     = 27
callsym   = 28
constsym  = 29
varsym    = 30
procsym   = 31
```

我们不需要记编号，只需要知道每个名字代表一种 Token 类别。

`odd` 很特殊，它虽然也是关键字，但在枚举中的编号 `oddsym` 是 7，夹在运算符中间，所以不能只通过编号范围判断全部关键字。

### 2.5 `extern` 变量声明

```c
extern FILE *fin;
extern char ch;
extern enum symbol sym;
...
```

`extern` 的意思是：这个名字是全局变量，真正的存储在 `.c` 文件里创建，头文件只是提前告诉别的文件“有这个名字”。

可以理解成“登记表”：头文件登记名字，源文件真正造盒子。

各个变量：

| 变量 | 类型 | 含义 |
| --- | --- | --- |
| `fin` | `FILE *` | 打开的源文件 |
| `ch` | `char` | 当前字符 |
| `sym` | `enum symbol` | 当前 Token 类别 |
| `id` | 字符数组 | 当前标识符或关键字 |
| `num` | `int` | 当前整数 |
| `cc` | `int` | 当前行中的字符位置 |
| `ll` | `int` | 当前行长度 |
| `cx` | `int` | 教材源码行首显示的代码地址 |
| `line` | `char[81]` | 当前源程序行 |
| `a` | `char[11]` | 暂存单词 |
| `word` | 二维字符数组 | 13 个保留字 |
| `wsym` | 枚举数组 | 保留字对应的符号 |
| `ssym` | 枚举数组 | 单字符对应的符号 |
| `err` | `int` | 错误数量 |

这些叫函数原型。它们告诉编译器：

## 3. 源文件开头和宏定义

```c
#include <stdio.h>
#include <string.h>

#include "pl0_t.h"

#define max_tokens 2048
#define token_text_size 128
```

`stdio.h` 提供文件操作和屏幕输出。

`string.h` 提供字符串复制和比较。

`pl0_t.h` 是教材版自己的头文件，编译命令通过 `-Iinclude` 指定搜索目录，不会误用完整编译系统的 `pl0.h`。

`max_tokens` 是 Token 数组的最大容量。

`token_text_size` 是每个 Token 字段最多保存多少字符。

## 4. `struct token_record` 逐行解释

```c
struct token_record {
    char word[token_text_size];
    char category[token_text_size];
    char value[token_text_size];
};
```

这一整段定义了一种新数据类型，叫 `struct token_record`。

它表示“一条 Token 记录”，里面包含三块字符数组：

| 成员 | 含义 | 例子 |
| --- | --- | --- |
| `word` | 源程序中的原单词 | `read`、`7`、`:=` |
| `category` | Token 分类 | `KEYWORD`、`IDENTIFIER` |
| `value` | 教材符号名或实际值 | `READSYM`、`m`、`7` |

`token_text_size` 已经定义为 128，所以每个成员都可以保存 127 个有效字符，最后再留一个位置放 `\0`。

## 5. 全局变量定义

```c
FILE *fin;
char ch;
enum symbol sym;
char id[al + 1];
int num;
int cc;
int ll;
int cx;
char line[81];
char a[al + 1];

```

这些变量在头文件里已经用 `extern` 声明过。这里才是真正创建它们。

### 5.1 `FILE *fin`

`fin` 指向打开的输入文件。

后面的：

```c
fgetc(fin)
```

表示从 `fin` 指向的文件读一个字符。

### 5.2 `char ch`

保存当前字符。

例如读到字母 `r`，那么：

```c
ch == 'r'
```

### 5.3 `enum symbol sym`

保存当前识别出的 Token 类别。

例如识别到 `read` 后：

```c
sym = readsym;
```

### 5.4 `char id[al + 1]`

因为 `al = 10`，所以实际是：

```c
char id[11];
```

最多保存 10 个字符，最后还有一个位置保存 `\0`。

### 5.5 `int num`

保存当前整数的值。

例如读到：

```text
85
```

那么：

```c
num == 85
```

### 5.6 `int cc` 和 `int ll`

这两个是读字符时最重要的位置变量。

假设读入了一行：

```text
const m
```

数组里可以看成：

```text
下标:  0    1    2    3    4    5    6
字符: 'c'  'o'  'n'  's'  't'  ' '  'm'
```

`ll` 表示这一行保存了多少个字符。

`cc` 表示当前读到哪个下标。

```c
ch = line[cc];
cc++;
```

意思是：

1. 读取 `line[cc]`
2. 把 `cc` 往后移动一个位置

### 5.7 `int cx`

教材源码回显时，每行前面会打印一个代码地址：

```text
0 const m = 7;
```

这个 `0` 就是 `cx`。本程序只做词法分析，所以它一直是 0。

### 5.8 `char line[81]`

保存当前源程序行，最多 80 个有效字符，最后留一个位置。

### 5.9 `char a[al + 1]`

临时保存正在读取的单词。

例如读到 `read` 时：

```text
a[0] = 'r'
a[1] = 'e'
a[2] = 'a'
a[3] = 'd'
a[4] = '\0'
```

### 5.10 `char word[norw][al]`

展开后：

```c
char word[13][10];
```

保存 13 个保留字。

### 5.11 `enum symbol wsym[norw]`

保存保留字和符号编号的对应关系。

例如：

```text
word[8] = "read"
wsym[8] = readsym
```

### 5.12 `enum symbol ssym[256]`

保存单字符和符号编号的对应关系。

例如：

```text
ssym['+'] = plus
ssym['#'] = neq
```

### 5.13 `int err`

记录检测到多少个错误。

## 7. 符号名称表

```c
static const char *symbol_name[] = {
    "NUL",      "IDENT",    "NUMBER",   "PLUS",     "MINUS",
    "TIMES",    "SLASH",    "ODDSYM",   "EQL",      "NEQ",
    "LSS",      "LEQ",      "GTR",      "GEQ",      "LPAREN",
```

这张表和 `enum symbol` 一一对应。

例如：

```c
symbol_name[2]
```

## 8. 符号文字表

```c
static const char *symbol_text[] = {
    "",     "",      "",      "+",    "-",
    "*",    "/",     "",      "=",    "#",
    "<",    "<=",    ">",     ">=",   "(",
    ")",    ",",     ";",     ".",    ":=",
    "begin","end",   "if",    "then", "while",
    "write","read",  "do",    "call", "const",
    "var",  "procedure"
};
```

这张表保存特殊符号在源程序里的实际写法。

例如：

```text
symbol_text[plus] == "+"
symbol_text[becomes] == ":="
symbol_text[neq] == "#"
```

## 9. `is_keyword_symbol()` 逐行解释

```c
static int is_keyword_symbol(void)
{
    return sym == oddsym || (sym >= beginsym && sym <= procsym);
}
```

这个函数返回“当前 `sym` 是不是关键字”。

分成两个条件：

```c
sym == oddsym
```

判断是不是 `odd`。

```c
sym >= beginsym && sym <= procsym
```

判断是不是从 `beginsym` 到 `procsym` 范围里的关键字。

中间的 `||` 表示“或者”。

判断顺序：

1. 如果 `sym` 是 `oddsym`，返回真。
2. 如果 `sym` 在 `beginsym` 到 `procsym` 之间，返回真。
3. 否则返回假。

## 10. `copy_text()` 逐行解释

```c
static void copy_text(char *dest, size_t size, const char *source)
{
    if (size == 0) {
        return;
    }
    strncpy(dest, source, size - 1);
    dest[size - 1] = '\0';
}
```

参数：

- `dest`：目标字符数组
- `size`：目标数组总大小
- `source`：要复制的原文字符串

### 第一步

```c
if (size == 0) {
    return;
}
```

如果目标数组大小是 0，直接结束。

### 第二步

```c
strncpy(dest, source, size - 1);
```

最多复制 `size - 1` 个字符。

留出最后一个位置给 `\0`。

### 第三步

```c
dest[size - 1] = '\0';
```

强制在数组最后放字符串结束符，保证不会读越界。

## 11. `add_token()` 逐行解释

```c
static void add_token(const char *word_text, const char *category,
                      const char *value)
{
    if (token_count >= max_tokens) {
        return;
    }

    copy_text(tokens[token_count].word,
              sizeof(tokens[token_count].word), word_text);
    copy_text(tokens[token_count].category,
              sizeof(tokens[token_count].category), category);
    copy_text(tokens[token_count].value,
              sizeof(tokens[token_count].value), value);
    token_count++;
}
```

这个函数负责往 Token 表里增加一行。

```c
if (token_count >= max_tokens) {
    return;
}
```

如果已经存满 2048 条，直接结束，防止数组越界。

```c
tokens[token_count].word
```

表示当前可写的 Token 记录的 `word` 成员。

连续调用三次 `copy_text`，分别复制：

- `word`
- `category`
- `value`

最后：

```c
token_count++;
```

让计数加 1，下一条 Token 就保存到下一个位置。

## 12. `record_error_token()` 和 `record_current_token()`

### 12.1 `record_error_token`

```c
static void record_error_token(const char *text, const char *message)
{
    add_token(text, "ERROR", message);
}
```

它只是 `add_token` 的简化写法。

类别固定写 `"ERROR"`。

### 12.2 `record_current_token`

```c
static void record_current_token(void)
{
    if (sym == ident) {
        add_token(id, "IDENTIFIER", id);
    } else if (sym == number) {
        add_token(number_text, "INTEGER", number_text);
    } else if (is_keyword_symbol()) {
        add_token(id, "KEYWORD", symbol_name[sym]);
    } else if (sym >= plus && sym <= becomes && sym != oddsym) {
        add_token(symbol_text[sym], "SPECIAL", symbol_name[sym]);
    } else if (sym == nul) {
        record_error_token("NUL", "unrecognized symbol");
    }
}
```

判断顺序不能随便换：

1. 当前是标识符，保存 `IDENTIFIER`
2. 当前是数字，保存 `INTEGER`
3. 当前是关键字，保存 `KEYWORD`
4. 当前是特殊符号，保存 `SPECIAL`
5. 当前是 `nul`，保存 `ERROR`

最后的特殊符号条件：

```c
sym >= plus && sym <= becomes && sym != oddsym
```

意思是编号在普通运算符范围中，但不是关键字 `odd`。

## 13. `error()` 逐行解释

```c
void error(int n)
{
    char space[81];
    int i;

    for (i = 0; i < 80; i++) {
        space[i] = ' ';
    }
    space[80] = '\0';

    if (cc > 0 && cc <= 80) {
        space[cc - 1] = '\0';
    }

    printf("****%s!%d\n", space, n);
    err++;
}
```

### 13.1 `char space[81]`

创建一个 81 个字符的数组，用来准备错误行前面的空格。

### 13.2 填空格循环

```c
for (i = 0; i < 80; i++) {
    space[i] = ' ';
}
```

把下标 0 到 79 填成空格。

### 13.3 放字符串结束符

```c
space[80] = '\0';
```

让 `space` 成为合法字符串。

### 13.4 截断到错误位置

```c
if (cc > 0 && cc <= 80) {
    space[cc - 1] = '\0';
}
```

让字符串在错误字符附近结束，这样 `!错误号` 会尽量对齐到出错的列。

### 13.5 输出错误

```c
printf("****%s!%d\n", space, n);
```

例如：

```text
****          !30
```

`%s` 输出空格，`%d` 输出错误编号。

最后：

```c
err++;
```

错误总数加 1。

## 14. `getch()` 逐行解释

完整代码：

```c
int getch(void)
{
    if (cc == ll) {
        if (input_finished) {
            printf("program incomplete\n");
            return -1;
        }

        ll = 0;
        cc = 0;
        printf("%d ", cx);

        while (1) {
            int c = fgetc(fin);
            if (c == EOF) {
                input_finished = 1;
                break;
            }
            ch = (char)c;
            printf("%c", ch);
            if (ll < 80) {
                line[ll++] = ch;
            }
            if (ch == '\n') {
                break;
            }
        }

        if (ll == 0 && input_finished) {
            printf("\nprogram incomplete\n");
            return -1;
        }

        if (ll < 80) {
            line[ll++] = ' ';
        }
        printf("\n");
    }

    ch = line[cc];
    cc++;
    return 0;
}
```

### 14.1 为什么先判断 `cc == ll`

```c
if (cc == ll)
```

`cc` 是当前读到第几个字符，`ll` 是这一行总长度。

当它们相等，表示当前行已经处理完，需要读取下一行。

### 14.2 文件是否结束

```c
if (input_finished) {
    printf("program incomplete\n");
    return -1;
}
```

如果已经读到文件末尾，仍要求继续读字符，就是异常情况。

程序打印：

```text
program incomplete
```

然后返回 `-1`，通知调用者停止。

### 14.3 准备读新行

```c
ll = 0;
cc = 0;
```

把行长度和当前位置都清零。

```c
printf("%d ", cx);
```

输出教材格式的行首编号。

### 14.4 无限循环读取整行

```c
while (1) {
    ...
}
```

`while (1)` 表示条件永远为真。

它不是死循环，因为循环里面会在遇到换行或文件末尾时执行 `break`。

### 14.5 读取一个字符

```c
int c = fgetc(fin);
```

从文件读一个字符，返回类型是 `int`。

为什么不用 `char`？

因为文件末尾需要用 `EOF` 表示，而 `EOF` 通常是 `-1`。使用 `int` 才能可靠区分正常字符和文件结束。

### 14.6 处理文件结束

```c
if (c == EOF) {
    input_finished = 1;
    break;
}
```

如果读到文件末尾：

1. 把 `input_finished` 设置为 1。
2. 用 `break` 跳出循环。

### 14.7 保存并回显字符

```c
ch = (char)c;
printf("%c", ch);
```

第一行把整数 `c` 转成字符放进 `ch`。

第二行把字符输出到屏幕，实现教材式源码回显。

### 14.8 保存到行数组

```c
if (ll < 80) {
    line[ll++] = ch;
}
```

如果还没有超过 80 个字符，就保存到 `line`。

```c
line[ll++] = ch;
```

分开写就是：

```c
line[ll] = ch;
ll = ll + 1;
```

### 14.9 遇到换行就结束本行

```c
if (ch == '\n') {
    break;
}
```

`'\n'` 是换行符。

读完整行后跳出循环。

### 14.10 空文件处理

```c
if (ll == 0 && input_finished) {
    printf("\nprogram incomplete\n");
    return -1;
}
```

如果一个字都没读到，而且文件结束了，也提示程序不完整。

### 14.11 行末空格

```c
if (ll < 80) {
    line[ll++] = ' ';
}
```

在行末追加一个空格，方便词法分析器处理行尾。

### 14.12 返回当前字符

```c
ch = line[cc];
cc++;
return 0;
```

顺序分成三步：

1. 把 `line[cc]` 放进 `ch`
2. `cc` 加 1，准备下一次读取下一个字符
3. 返回 0，表示正常

## 15. `init()` 逐行解释

```c

    strcpy(word[0], "begin");

    wsym[1] = callsym;
    wsym[2] = constsym;
    wsym[3] = dosym;
    wsym[4] = endsym;
    wsym[5] = ifsym;
    wsym[6] = oddsym;
    wsym[7] = procsym;
    wsym[8] = readsym;

```

### 15.1 清空 `ssym`

```c
for (i = 0; i < 256; i++) {
    ssym[i] = nul;
}
```

先把所有单字符都设成“不认识”。

### 15.2 登记单字符

```c
ssym['+'] = plus;
```

以后读到 `+`，通过：

```c
sym = ssym[(unsigned char)ch];
```

就能得到 `plus`。

### 15.3 登记保留字

```c
strcpy(word[0], "begin");
```

把文本 `"begin"` 复制到保留字表第 0 项。

保留字必须按字母顺序排列，因为后面使用折半查找。

### 15.4 登记保留字对应的符号

```c
wsym[0] = beginsym;
```

表示：

```text
word[0] 是 "begin"
它对应的 Token 类别是 beginsym
```

其他项同理。

### 15.5 清空 Token 计数和文件状态

```c
token_count = 0;
```

新的一次扫描从 0 条 Token 开始，文件也还没结束。

## 16. `getsym()` 逐段解释

### 16.1 函数声明和局部变量

```c
int getsym(void)
{
    int i;
    int j;
    int k;
    int identifier_too_long;
```

返回值：

```text
0   正常识别出一个 Token
-1  遇到异常 EOF
```

局部变量：

- `i`、`j`、`k`：折半查找和数组下标
- `identifier_too_long`：标识符是否超过 10 个字符

### 16.2 跳过空白

```c
while (1) {
    while (ch == ' ' || ch == '\n' || ch == '\r' || ch == '\t') {
        if (getch() == -1) {
            return -1;
        }
    }
```

外层 `while (1)` 是为了处理“空白后面接注释，注释后面又接空白”的情况。

内层循环负责跳过四种无意义字符：

- 空格
- 换行
- 回车
- 制表符

### 16.3 识别注释

```c
if (ch == '/') {
    if (getch() == -1) {
        return -1;
    }
    if (ch == '*') {
        ...
        continue;
    }

    sym = slash;
    record_current_token();
    return 0;
}
```

先看 `/` 后面一个字符。

如果后面是 `*`，就是注释开头。

如果后面不是 `*`，就是除法符号。

### 16.4 注释内部

```c
while (1) {
    if (ch == '*') {
        if (getch() == -1) {
            error(38);
            return -1;
        }
        if (ch == '/') {
            if (getch() == -1) {
                return -1;
            }
            break;
        }
    } else if (getch() == -1) {
        error(38);
        return -1;
    }
}
```

这个循环一直找 `*/`。

- 看到 `*`，再读一个字符
- 如果下一个是 `/`，注释结束
- 其他字符直接跳过
- 文件结束前还没找到 `*/`，报错误 38

### 16.5 识别标识符或关键字

```c
if (ch >= 'a' && ch <= 'z') {
    k = 0;
    identifier_too_long = 0;
```

只有小写字母开头才进入这里。

```c
do {
    if (k < al) {
        a[k] = ch;
        k++;
    } else {
        identifier_too_long = 1;
    }
    if (getch() == -1) {
        return -1;
    }
} while ((ch >= 'a' && ch <= 'z') || (ch >= '0' && ch <= '9'));
```

循环条件表示：

```text
还是小写字母
或者
还是数字
```

如果是，就继续读。

最多保存 10 个字符，超过就把 `identifier_too_long` 设为 1。

```c
a[k] = '\0';
strcpy(id, a);
```

给临时单词补上结束标志，再复制到 `id`。

### 16.6 检查标识符长度

```c
if (identifier_too_long) {
    error(36);
    record_error_token(id, "identifier is longer than 10 characters");
}
```

如果超过 10 个字符，打印错误并往 Token 表增加 ERROR 行。

### 16.7 折半查找保留字

```c
i = 0;
j = norw - 1;
```

搜索范围是 0 到 12。

```c
do {
    k = (i + j) / 2;
    if (strcmp(id, word[k]) <= 0) {
        j = k - 1;
    }
    if (strcmp(id, word[k]) >= 0) {
        i = k + 1;
    }
} while (i <= j);
```

每次取中间位置：

```text
k = (i + j) / 2
```

`strcmp` 比较两个字符串：

```text
小于 0  左边更小
等于 0  完全相同
大于 0  左边更大
```

根据结果缩小搜索范围。

```c
if (i - 1 > j) {
    sym = wsym[k];
} else {
    sym = ident;
}
```

找到保留字就用 `wsym` 转成对应符号，否则就是普通标识符。

### 16.8 识别整数

```c
} else if (ch >= '0' && ch <= '9') {
    k = 0;
    i = 0;
    num = 0;
    sym = number;
```

- `k` 统计位数
- `i` 保存数字文本的位置
- `num` 保存数值
- `sym` 先标记为数字类型

```c
do {
    if (i < (int)sizeof(number_text) - 1) {
        number_text[i] = ch;
        i++;
    }
    num = 10 * num + ch - '0';
    k++;
    if (getch() == -1) {
        return -1;
    }
} while (ch >= '0' && ch <= '9');
```

每读到一个数字：

1. 把原字符存进 `number_text`
2. 用数学公式合并成整数
3. 位数加 1
4. 继续读下一个字符

```c
number_text[i] = '\0';
```

补字符串结束符。

```c
k--;
if (k > nmax) {
    error(30);
}
```

检查是否超过 14 位。

```c
if (ch >= 'a' && ch <= 'z') {
    error(39);
    record_error_token("", "number cannot be followed by a letter");
}
```

例如 `12abc`，数字后面直接接字母，记录错误。

### 16.9 识别 `:=`

```c
} else if (ch == ':') {
    if (getch() == -1) {
        return -1;
    }
    if (ch == '=') {
        sym = becomes;
        if (getch() == -1) {
            return -1;
        }
    } else {
        sym = nul;
        error(19);
        record_error_token(":", "':' must be followed by '='");
        return 0;
    }
}
```

看到冒号后必须再看一个字符：

- 下一个是 `=`：组成 `:=`
- 下一个不是 `=`：输出错误 19

### 16.10 识别 `<` 和 `<=`

```c
} else if (ch == '<') {
    if (getch() == -1) {
        return -1;
    }
    if (ch == '=') {
        sym = leq;
        if (getch() == -1) {
            return -1;
        }
    } else {
        sym = lss;
    }
}
```

`<` 的两种情况：

```text
<=  小于等于，sym = leq
<   小于，sym = lss
```

### 16.11 识别 `>` 和 `>=`

```c
} else if (ch == '>') {
    if (getch() == -1) {
        return -1;
    }
    if (ch == '=') {
        sym = geq;
        if (getch() == -1) {
            return -1;
        }
    } else {
        sym = gtr;
    }
}
```

`>` 的两种情况：

```text
>=  大于等于，sym = geq
>   大于，sym = gtr
```

### 16.12 其他单字符

```c
} else {
    sym = ssym[(unsigned char)ch];
```

通过字符查表。

`(unsigned char)` 是类型转换，把 `ch` 变成 0 到 255 范围内的无符号字符，避免负数下标。

```c
if (sym == nul) {
    char invalid[4];
    invalid[0] = ch;
    invalid[1] = '\0';
    error(37);
    record_error_token(invalid, "illegal character");
    getch();
    return 0;
}
```

查不到就是非法字符。

例如 `@` 会进入这里。

```c
if (sym != period) {
    getch();
}
```

如果不是结束程序的句号 `.`，就继续读下一个字符。

句号后面不再读取，是因为主循环看到 `period` 就会停止。

### 16.13 记录 Token

```c
record_current_token();
return 0;
```

所有分类完成后，把当前 `sym` 转换成表格中的一行。

返回 0 表示成功识别一个 Token。

## 17. `print_tokens()` 逐行解释

```c
void print_tokens(void)
{
    int i;

    printf("\nWord                Category            Value\n");
    for (i = 0; i < token_count; i++) {
        printf("%-20s%-20s%-20s\n",
               tokens[i].word,
               tokens[i].category,

    }
}
```

```c
int i;
```

循环时使用。

```c
printf("\nWord                Category            Value\n");
```

先输出表头和换行。

```c
for (i = 0; i < token_count; i++)
```

从第 0 条输出到最后一条。

```c
printf("%-20s%-20s%-20s\n",
       tokens[i].word,
       tokens[i].category,
       tokens[i].value);
```

- `%-20s`：字符串占 20 个字符宽，左对齐
- 三个 `%-20s`：输出三列
- 最后的 `\n`：换行

## 18. `main()` 逐行解释

```c
int main(int argc, char **argv)
```

`main` 是程序入口。

- `argc` 是命令行参数个数
- `argv` 是保存参数的字符指针数组

例如执行：

```bat
pl0_textbook.exe lexical-analysis\c-textbook\tests\basic.pl0
```

那么：

```text
argc = 2
argv[0] = "pl0_textbook.exe"
argv[1] = "lexical-analysis\\c-textbook\\tests\\basic.pl0"
```

```c
char fname[256];
```

保存文件名，最多 255 个字符，再留一个位置给 `\0`。

```c
printf("Input pl/0 file?   ");
```

输出教材风格的提示。

### 18.1 有命令行参数

```c
if (argc > 1) {
    strncpy(fname, argv[1], sizeof(fname) - 1);
    fname[sizeof(fname) - 1] = '\0';
    printf("%s\n", fname);
}
```

如果用户运行程序时已经带了文件名，就直接使用 `argv[1]`。

`strncpy` 最多复制 255 个字符，然后手工补 `\0`，防止文件名过长。

### 18.2 没有命令行参数

```c
else {
    if (scanf("%255s", fname) != 1) {
        printf("\n");
        return 1;
    }
}
```

从键盘读取文件名。

`%255s` 表示最多读 255 个字符。

如果读取失败，换行并返回 1。

### 18.3 打开文件

```c
fin = fopen(fname, "r");
if (fin == NULL) {
    printf("Can't open file!\n");
    return 1;
}
```

`"r"` 表示只读打开。

如果返回 `NULL`，说明文件打不开。

### 18.4 初始状态

```c
init();
cc = 0;
cx = 0;
ll = 0;
err = 0;
ch = ' ';
```

`init()` 建立表格。

后面六个变量设置成起始状态。

`ch = ' '` 是为了让第一次进入 `getsym()` 时先跳过空白并读取真正内容。

### 18.5 主循环

```c
while (sym != period) {
    if (getsym() == -1) {
        break;
    }
}
```

表示：

```text
只要当前符号不是句号
    就继续识别下一个 Token
```

`period` 对应 PL/0 程序末尾的 `.`。

### 18.6 输出和收尾

```c
print_tokens();
printf("\n");
fclose(fin);
return err == 0 ? 0 : 1;
```

- `print_tokens()`：输出 Token 表
- `printf("\n")`：最后留一个空行
- `fclose(fin)`：关闭文件
- 最后一行是三目运算符

等价于：

```c
if (err == 0) {
    return 0;
} else {
    return 1;
}
```

当前 `ch` 是空格。

## 20. 常见 C 语言陷阱

### 20.1 `=` 和 `==`

```c
a = b;    // 赋值
a == b;   // 比较
```

代码里：

```c
if (cc == ll)
```

一定不能写成 `cc = ll`。

### 20.2 数组从 0 开始

```text
line[0] 是第 1 个字符
line[1] 是第 2 个字符
```

所以 `cc - 1` 才表示当前字符下标。

### 20.3 `++` 的位置

```c
cc++;
```

和：

```c
++cc;
```

在单独使用时效果一样。

但：

```c
line[ll++] = ch;
```

是“先用旧下标，再让 `ll` 加 1”。

### 20.4 `&&` 和 `||`

```text
&&  而且
||  或者
```

### 20.5 EOF

`EOF` 不是文件里的一个普通字符，而是文件结束标志。

### 20.6 `\0`

字符串末尾必须放 `\0`。

没有它，`printf("%s", ...)` 可能一直往后读，直到遇到别处的 0。

### 20.7 `static`

本文件里的：

```c
static int token_count;
```

只能被当前 `.c` 文件访问。

### 20.8 `extern`

头文件只是在声明：

```c
extern int num;
```

真正创建 `num` 的位置是 `.c` 文件里的：

```c
int num;
```
