1.  Q：为什么 CURRENT_USER 可以去掉括号？

    A： 它既是函数，也是伪列（保留字）
        在 ANSI SQL 标准中，CURRENT_USER 被定义为一个上下文信息项（Context Information），类似于 CURRENT_DATE（当前日期）或 CURRENT_TIMESTAMP（当前时间戳）。这些东西本质上是关键字级别的常量，不需要像普通函数那样通过 () 去执行计算。
        所以下面三种写法在 MySQL 里完全等价：
        SELECT CURRENT_USER;
        SELECT CURRENT_USER();
        SELECT SESSION_USER();
        不加括号时，MySQL 把它当成一个系统变量/伪列直接读取；
        加上括号时，MySQL 把它当成函数调用来执行并返回。

2.  Q：CURRENT_USER()和USER（）有啥区别？
    A：USER() 是你进门时报的“自称”；CURRENT_USER() 是酒店系统里实际登记、拥  有房间权限的“会员账号”。
    核心区别：连接身份 vs 授权身份
    在 MySQL 里，你通过客户端连上数据库时，实际上经历了两步：
    TCP/IP 连接：你告诉 MySQL 你的用户名和来源 IP（这就是 USER() 看到的）。
    权限校验：MySQL 拿着你的用户名和 IP，去 mysql.user 权限表里一条条匹配，找到那条最吻合的规则，赋予你对应的身份（这就是 CURRENT_USER() 看到的）。
