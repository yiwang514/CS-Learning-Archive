# Linux基本常识

## 三种网络链接模式

世界中的事物都不是孤立存在的，网络配置就是决定你的Linux系统如何与外部世界（物理机，互联网）建立联系。

**1.桥接模式：**

也就是Linux虚拟机和Windows宿主机是完全平等的。虚拟机直接可以链接到你家里的路由器，可以去申请一个独立的IP地址。

**本质：**虚拟机作为一个独立的实体去与外界进行交互。

**主要矛盾：** 优点是外部局域网的其他设备可以直接访问这台Linux（适合做真实的服务器测试）；缺点是它受制于外部网络环境，如果你的校园网或公司网络限制了IP数量，桥接就会失败。



2.**NAT模式**（网络地址转换）：：“对立统一”的辩证妥协

这个模式下，虚拟机不直接与路由器访问，而是通过宿主机去与外界世界链接。宿主机会为其构造一个内部世界，这个世界里，windows宿主机会虚拟出一张网卡（用代码模拟的虚拟硬件），Linux也会有一张网卡，它俩通过这个虚拟网段互通。当Linux想要上网时候就把请求发送给宿主机的虚拟网卡，宿主机再用自己真实的物理网卡去外部网络拿数据。

这样做就解决了桥接模式下的主要矛盾——IP冲突（ip地址有限，虚拟机会去和真实网络抢IP，容易冲突）。

**3.主机模式：**

这个模式更独裁了，只允许虚拟机和宿主机进行通信，不予许访问外网了。

**应用场景：** 当你在进行高危的病毒测试，或者搭建一个完全不需要外网的内部集群环境时，这种“孤立”就是保护系统安全的最佳实践
