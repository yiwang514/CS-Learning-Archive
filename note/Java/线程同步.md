**线程同步**就是通过**临界资源状态（也就是锁）**+ **通信信号**来实现线程同步。

大白话就是：先把要用的共享资源先锁上，线程就按照我们设计的信号来决定谁来用。

而线程同步情形就可以先大致分成**三种**，1.是两线程共享一个资源，而这个资源里有两种功能能使这两线程进行合作联系，也就使两线程干不同活。2.是多种线程要轮流干一种活。3.是两线程中共享多个资源。



首先第一种：

​	共享资源里面得要有信号吧（不然咋来辨别谁才能用它），其他还要有什么成员属性就看你具体要啥了。主要就是这个信号，在方法体里面用到。首先：肯定是判断这个信号（作为只有一个缓存区，那么也信号就是一种，要么有要么无），如果你不满足使用信号要求，那就给我wait（），没到你使用的时候呢！如果信号满足了，那就必须给我干两件事：1.改变信号量，也就是告诉共享资源下一次，就是喊这个暗号的线程来用你了。2.通知notify正在等待的线程，可以去用共享资源了。然后方法体具体该干啥干啥。

注：1.一般信号的初始值决定了开始的使用流程。

​		2.别忘了wait（）时要用try catch语句将InterruptedException 捕获。

而线程体里面首先得有共享资源对象吧，然后构造函数初始化一下共享资源对象，不然哪里知道是用哪个共享资源。然后在run方法里就写你线程该干啥。



然后第二种：

​	毕竟是多种线程轮流干同一种活吧，那就在线程类run方法里面写好线程该干的活。但是前面得先判断是轮到谁该干了吧——那就轮到共享资源干活了。共享资源就作为锁，判断现在是谁能用，不能用的就wait。能用的就同样干那两件事。

​	然后线程类中比第一种多了几种成员，也是根据需求来的。比如多了线程所分到的信号值，和它的下一个线程所分到信号值。构造函数就初始化下它们。



最后第三种：

​	公用多种共享资源（以二种举例）（这两种资源是同类型的），那么信号有两个才能来区分谁来使用共享资源吧，也就是isfull和isempty。全满和全空来判断。大致和第一种类似，就是多了个成员 如int next=0来判断你现在用的是哪一个共享资源
