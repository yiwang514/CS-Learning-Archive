# Java List 核心知识点总结笔记 📦

## 1. 基础概念与声明

- **List** 是一个接口（Interface），代表**有序、可重复、长度可变**的容器。
- **泛型（Generics）** `< >`：用于限定列表中只能存放哪种类型的数据，必须使用**包装类**（如 `Integer` 代替 `int`，`Double` 代替 `double`）。
- **多态声明**：推荐左边写接口，右边写实现类，方便后期灵活修改。

```
List<Integer> list = new ArrayList<>(); 
```

**注：a**.`<>`（菱形语法）：这是一个偷懒的写法。因为左边已经写了 <String>，右边就不需要再重复写一遍了，Java 会自动推断出来。

**b.**`  ArrayList` 是实现类：它是 `List` 接口的具体实现。它告诉计算机：“我会用‘动态数组’的方式来管理这些字符串。

## 2. 常用操作 API (以 ArrayList 为例)

- **添加 (Add)**：
  - `add(element)`：在末尾追加元素。
  - `add(index, element)`：在指定索引处插队，其后元素整体后移。
- **删除 (Remove)**：
  - `remove(index)`：按位置删除，其后元素整体前移填补空位。
  - `remove(Object)`：按内容删除匹配的第一个元素。
- **修改与查询 (Update & Query)**：
  - `set(index, element)`：替换指定位置的元素，列表长度（size）不变。
  - `get(index)`：获取指定位置的元素。
  - `indexOf(Object)`：查找元素第一次出现的索引，**找不到则返回 `-1`**。
  - `size()`：获取列表中元素的总个数。
  - `isEmpty()`：判断列表是否为空。
  - `clear()`：清空所有元素。

## 3. ArrayList vs LinkedList 性能对比 ⚖️

| **特性**              | **ArrayList (动态数组) 🚀** | **LinkedList (双向链表) 🔗**        |
| --------------------- | -------------------------- | ---------------------------------- |
| **底层结构**          | 连续的内存空间             | 节点互相关联，物理内存不连续       |
| **按索引查找**        | **极快**                   | 慢（需从头顺序访问）               |
| **中间/头部插入删除** | 慢（需大量移动元素）       | **极快**（只需改变前后节点的引用） |
| **适用场景**          | **读多写少**（默认首选）   | 频繁在两端或中间增删元素           |

## 4. 列表的遍历与安全删除 🔄

- **增强型 for 循环 (for-each)**：最常用、最简洁的遍历方式。

```
for (Integer num : list) {
    System.out.println(num);
}
```

- **迭代器 (Iterator)**：在遍历过程中**安全删除**元素的唯一传统方式，避免抛出 `ConcurrentModificationException`。

```
Iterator<Integer> it = list.iterator();
while (it.hasNext()) {
    if (it.next() > 15) {
        it.remove(); // 安全删除当前指针走过的元素
    }
}
```

## 5. Stream 流处理 (Java 8+ 现代化玩法) 🌊

Stream API 允许我们像流水线一样（声明式链式编程）优雅地处理集合数据。

- **快速建表**：`Arrays.asList("A", "B", "C")` 可以快速生成一个**定长**列表。
- **常用中间操作**（返回新 Stream）：
  - `filter(条件)`：过滤保留符合条件的元素 🔍
  - `map(转换逻辑)`：将元素映射转变成新形态 ✨
  - `distinct()`：自动去重
  - `sorted()`：排序
- **终端操作**（结束流并打包）：
  - `.toList()`：收集为常规列表。
  - `.collect(Collectors.toSet())`：收集为集合（附带去重效果，但无序）。

```
// 示例：去重并转大写
List<String> result = names.stream()
    .distinct()                 
    .map(s -> s.toUpperCase())  
    .toList();                  
```



#### Stream 的编程格式是什么？为什么能这么写？

------

这种格式被称为**链式编程（Method Chaining）**。

#### 为什么能这么写？（原理）

这种写法之所以成立，是因为 Stream 中的**中间操作**（如 `distinct`、`map`）都有一个共同点：**它们在处理完数据后，会返回一个新的 Stream 对象。**

我们可以把这个过程看作是“接力赛”：

1. `names.stream()`：把列表变成一个“流”对象。
2. `.distinct()`：流对象调用了自己的方法，去重后又返回了一个**新的**流对象。
3. `.map(...)`：新的流对象再次调用方法，转换后又返回了一个**新的**流对象。

因为每一次调用都返回一个可以继续调用方法的对象，所以你可以一直用点 `.` 连着写下去。

#### 这种格式的好处：

这种风格叫作**声明式编程（Declarative Programming）**。

- **命令式（传统方式）**：你告诉计算机“怎么做”（先建个循环，再建个判断，再加进新列表）。
- **声明式（Stream）**：你告诉计算机“想要什么”（我要去重的、我要大写的、我要收集成列表）。



**注：**`Arrays.asList()`这是一个**快捷工具方法**。它的作用是把一个数组（或者一串散落的元素）快速转换成一个 `List` 集合。
**它的底层**：它返回的其实是 `Arrays` 类内部的一个私有列表。

**一个小陷阱**：这个生成的列表长度是**固定**的。
