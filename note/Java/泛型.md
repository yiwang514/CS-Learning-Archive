## 1. 泛型是什么？

泛型就是“**类型参数化**”——把类型像变量一样传递。
比如我们写一个盒子类，不固定里面装什么类型的东西，用 `` 表示“某种类型”，等到真正用的时候再指定具体类型（String、Integer等）。

**代码示例**：

java

```
// 定义一个泛型类 Box，T 是类型参数
public class Box<T> {
    private T item;
    public void set(T item) { this.item = item; }
    public T get() { return item; }
}

// 使用：指定 T 为 String
Box<String> box = new Box<>();
box.set("Hello");
String str = box.get();   // 直接得到 String，不用强转
```



## 2. 为什么需要泛型？

在没有泛型的年代，我们写通用代码只能靠 `Object`，然后到处强转，非常容易出错。

**旧方式（没泛型）**：

java

```
List list = new ArrayList();
list.add("hello");
list.add(123);        // 不小心混入 Integer，编译器不报错
String s = (String) list.get(1); // 运行时 ClassCastException 💥
```



**有了泛型**：

java

```
List<String> list = new ArrayList<>();
list.add("hello");
// list.add(123);      // 编译就报错，提前发现错误
String s = list.get(0); // 直接拿 String，无需强转
```



**好处**：

- ✅ **编译时类型安全**（放错类型直接报错）
- ✅ **消除强制转换**（代码更干净）
- ✅ **代码复用**（一套逻辑适用于多种类型）

## 3. 泛型的使用方式

### 3.1 泛型类 / 泛型接口

在类名后加 ``，可以定义多个类型参数，比如 `Map`。

java

```
// 泛型接口
public interface Pair<K, V> {
    K getKey();
    V getValue();
}

// 实现时指定具体类型
public class OrderPair<K, V> implements Pair<K, V> {
    private K key;
    private V value;
    // 构造方法、getter...
}
```



### 3.2 泛型方法

方法自己定义类型参数，放在返回值前面。

java

```
public <T> T doSomething(T value) {
    // 处理 value...
    return value;
}

// 调用：编译器自动推断 T 为 String
String result = doSomething("test");
```



### 3.3 注意事项

- 泛型参数只能用引用类型，不能用基本类型（比如 `int` 得用 `Integer`）。
- 泛型类中的静态方法不能使用类的泛型参数，因为静态成员属于类，而泛型参数是实例化时才确定。

## 4. 类型擦除——泛型的“秘密”

Java 的泛型是**编译期**的假象，虚拟机根本不认识泛型。编译器会做两件事：

1. **把类型参数替换为 Object**（或指定上限）。
2. **自动插入强制转换**。

**编译前**：

java

```
Box<String> box = new Box<>();
box.set("hello");
String s = box.get();
```



**编译后（擦除后）**：

java

```
Box box = new Box();          // 原始类型
box.set("hello");
String s = (String) box.get(); // 插入强转
```



**结论**：运行时 `Box` 和 `Box` 是同一个类，无法用 `instanceof` 区分具体泛型类型。

## 5. 通配符（?）——处理未知类型

当你不确定泛型的具体类型时，用 `?` 表示“任意类型”。

### 5.1 无界通配符 `?`

java

```
public void printList(List<?> list) {
    for (Object obj : list) {
        System.out.println(obj);
    }
}
```



- 可以读取（元素都是 `Object`）
- 不能写入（除了 null），因为不知道具体类型，怕放错。

### 5.2 上界通配符 `? extends T`

表示类型必须是 **T 或 T 的子类**。

java

```
public double sum(List<? extends Number> list) {
    double total = 0;
    for (Number n : list) {
        total += n.doubleValue();
    }
    return total;
}
```



- 可以安全读取（当作 T 或父类读）
- 不能写入（除了 null），因为不知道具体是哪个子类。

### 5.3 下界通配符 `? super T`

表示类型必须是 **T 或 T 的父类**。

java

```
public void addNumbers(List<? super Integer> list) {
    list.add(10);   // 可以添加 Integer，因为任何父类都能装下 Integer
    list.add(20);
}
```



- 可以写入 T 类型的数据
- 读取时只能当作 `Object` 读（因为可能是任意父类）

### 5.4 PECS 原则（Producer Extends, Consumer Super）

- 如果你**读取**数据（生产者），用 `? extends`
- 如果你**写入**数据（消费者），用 `? super`

------

## 6. 泛型的常见限制（坑点）

由于类型擦除，泛型有一些限制：

| 限制                               | 原因                         | 示例                                           |
| :--------------------------------- | :--------------------------- | :--------------------------------------------- |
| **不能实例化泛型类型**             | 运行时不知道 T 具体是什么    | `new T()` ❌                                    |
| **不能创建泛型数组**               | 数组在运行时需要知道具体类型 | `T[] arr = new T[10]` ❌                        |
| **不能使用基本类型**               | 类型参数必须是引用类型       | `List` ❌ 用 `List` ✅                           |
| **不能使用 `instanceof` 检查泛型** | 运行时泛型被擦除             | `list instanceof List` ❌ 只能用原始类型 `List` |
| **静态上下文中不能引用类泛型参数** | 静态成员属于类，不依赖实例   | `public static T get() { ... }` ❌              |

------

## 7. 总结一句话

泛型就是**让代码既能复用多种类型，又能保证类型安全**，通过编译期的检查和类型擦除来实现。
掌握泛型类、泛型方法、通配符的使用，就能写出更灵活、更健壮的代码。
