# 📝 Java Lambda & Stream 核心知识点通俗指南

## 一、 Lambda 表达式的本质

**一句话理解：** 把一段“行为”或“动作”像变量一样传来传去。它是用来**替代冗长的匿名内部类**的语法糖，让代码变得极其精简。
和匿名内部类都是创建**实例**的一种语法形式。

- **基本语法格式**：`(参数列表) -> { 执行逻辑 }`
- **箭头 `->`**：可以读作“传递给”或“去执行”。

Java

```
// 旧写法：匿名内部类
Runnable r1 = new Runnable() {
    @Override
    public void run() {
        System.out.println("跑起来！");
    }
};

// 新写法：Lambda
Runnable r2 = () -> System.out.println("跑起来！");
```

### 注：a.匿名内部类是什么？

匿名内部类是一种**没有名字的局部类**，它通常用于**一次性实现一个接口或继承一个抽象类**，并立即创建其实例。语法格式为：

java

```
new 接口/类(参数列表) {
    // 实现接口或重写方法
};
```

### **b.区别**

虽然Lambda是用来代替**匿名内部类**，但它们还是有区别的。
	就是Lambda只能是创建**函数式接口（有且仅有一个抽象方法**）的实例，而**匿名内部类**可以用于**任何接口**（无论含有多少个抽象方法）、**抽象类**，甚至是**具体类**（通过重写方法）。它能够访问**外部变量**（需要是 effectively final）。

## 二、 灵魂基石：函数式接口

Lambda 不能凭空存在，它必须依附于一个“坑位”，这个坑位就是**函数式接口**。

- **定义**：有且仅有**一个抽象方法**的接口。
- **标志**：通常带有 `@FunctionalInterface` 注解（用于让编译器帮你检查是否写多了方法）。

**Java 内置的“四大天王”（位于 `java.util.function`）：**

| **接口名称**  | **泛型格式** | **核心方法**        | **讲人话**                                          | **典型场景**                                          |
| ------------- | ------------ | ------------------- | --------------------------------------------------- | ----------------------------------------------------- |
| **Predicate** | ``           | `boolean test(T t)` | **裁判**：给它一个东西，它告诉你对不对。            | 判断数字是否大于 100 (`n -> n > 100`)                 |
| **Consumer**  | ``           | `void accept(T t)`  | **消费者**：给它一个东西，它用掉，不给反馈。        | 打印接收到的名字 (`name -> System.out.println(name)`) |
| **Function**  | ``           | `R apply(T t)`      | **加工厂**：给它原材料 `T`，它加工成产品 `R` 返回。 | 把字符串转成大写 (`s -> s.toUpperCase()`)             |
| **Supplier**  | ``           | `T get()`           | **生产商**：不给它任何东西，它凭空产出一个。        | 生成一个随机数 (`() -> Math.random()`)                |

**注**：**a.**如果试图将 Lambda 表达式赋值给一个**非函数式接口**（即含有多个抽象方法的接口），编译器会报错。

​		**b.**自己创建的函数式接口也能用Lambda表达式。

## 三、 Lambda 语法“瘦身术”

Lambda 追求极致的简洁，编译器能猜到的东西，统统可以省略：

1. **省略类型**：`(String s) -> ...` 可以简写为 `(s) -> ...`
2. **省略小括号**：如果只有**一个参数**，小括号不要了 ➡️ `s -> ...`
3. **省略大括号和 return**：如果逻辑只有**一行代码**，`{}` 和 `return` 必须同时省略 ➡️ `n -> n * 10`

### 终极大招：方法引用与构造器引用 (`::`)

如果你的 Lambda 只是把参数原封不动地交给另一个方法或构造函数去执行，就可以用双冒号 `::`。

Java

```
// 普通 Lambda
Consumer<String> c = s -> System.out.println(s);
Function<String, File> f = path -> new File(path);

// 方法/构造器引用 (逼格拉满)
Consumer<String> c = System.out::println;
Function<String, File> f = File::new;
```

## 四、 Stream API：流水线作业

Stream 结合 Lambda，是 Java 8 处理集合（如 List）的神器。它采用**链式编程**（换行加 `.` 的形式），让数据像在流水线上一样被一步步加工。

**核心工位（操作）：**

- `.filter(Predicate)`：**质检员**，筛掉不符合条件的元素。
- `.map(Function)`：**加工员**，把元素转换成另一种形态。
- `.forEach(Consumer)`：**收尾员**，对最终留下的元素逐个执行操作（属于终止操作，一旦执行流水线就结束了）。

**经典代码段：筛选偶数、放大 10 倍并打印**

Java

```
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5, 6);

numbers.stream()                     // 1. 把集合放上流水线
    .filter(n -> n % 2 == 0)         // 2. 质检：只留下偶数 (2, 4, 6)
    .map(n -> n * 10)                // 3. 加工：通通乘以 10 (20, 40, 60)
    .forEach(System.out::println);   // 4. 收尾：逐个打印出来
```
